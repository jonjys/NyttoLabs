# Nine-product portal

## Scope

This release adds a presentation-only catalog in `lib/portal/catalog.js`, a responsive home and product directory, browser-local bookmarks, search, app icons, a web app manifest and a social preview image.

The existing home and products view components remain in the repository. The page entrypoints render the new portal. Contact, partner inquiries, legal pages, admin, redirects and all existing API routes retain their functions.

No database schema, environment variable, Relay catalog, authentication, billing, partner-routing or product backend is changed. The public portal catalog does not enroll apps into Relay.

## Product readiness observed

- CycleTag's example QR opens a replacement page with EPN campaign `5339198614`. This verifies link construction, not commissions or payouts.
- CycleTag Bulk still has a public `/bulk` generator. Stripe payment alone does not enforce access. The portal promotes free labels and does not promise a secured paid entitlement.
- GetGateZero's workspace setup page is reachable. No workspace, provider-key vault or paid proxy request was created in this review.
- Curl-to-Buy displays demo mode with simulated checkout.
- Webhook Witness describes a free MVP and an inactive paid tier.
- RFQ Stamp and Ragefile describe preview/demo paid-export unlocks rather than completed Stripe checkout.
- FailClosed remains a private beta. AI Venture Worker remains a private inventory-audit pilot.

## App preparation

The manifest starts at `/products`, uses standalone display and provides 192px and 512px icons. Bookmarks are stored only in `nyttolabs:portal:saved:v1` in the browser, with storage-failure handling. There is no new shared login or cross-domain session. No service worker caches account, payment or API responses. This is a web portal with home-screen metadata, not a native App Store release or an offline app.

## Validation

- `npm test` runs existing Relay/site tests plus catalog search, saved-data parsing and the exact nine-domain mapping.
- `npm run build` prerenders the portal and image assets. Existing API and redirect routes remain dynamic.
- The review uses an isolated build directory so unrelated parent-repository lint configuration and dependencies cannot affect this project.
- Inspect search, saved products across reload, product links, page metadata and social image in the preview before promoting the same commit.

## Reversibility

The portal is isolated in new modules. Reverting this release restores the previous page imports and presentation; no database rollback is needed. Do not delete or reset application data to roll back this UI.
